# lit-essay — 문학·에세이 독후감

> **공통 규약을 먼저 읽는다** → [`_common.md`](_common.md)

읽고 남기는 글. **압축 + 인상**이다. `tech-essay` 가 평가와 적용이라면
여기는 **무엇이 남았는가**다.

옵션: `level` · `density`

## ① 아웃라인 — 남은 것에서 거꾸로 세운다

1. 책 메타와 목차(있으면)를 보고 **이 책에서 가장 오래 남을 한 가지**를 정한다
2. 그게 어디에서 왔는지 **장 2~4개**를 고른다
3. 줄거리는 **한 칸**만 쓴다 — 더 쓰면 독후감이 요약이 된다

| 칸 종류 | 수 | `chapterId` |
|---|---|---|
| 무슨 이야기였나 — 5줄 이내, 결말 없이 | 1 | null |
| **남은 대목** — 한 칸에 하나 (인용 + 왜) | 2~4 (`density`) | 해당 장 |
| 남는 생각 | 1 | null |

`density`: `simple` 2칸 · `standard` 3칸 · `full` 4칸

> 아웃라인을 사람에게 보일 때 **"가장 오래 남을 한 가지"로 무엇을 골랐는지 먼저 말한다.**
> 그게 다르면 글 전체가 다르다.

## ② 칸 채우기

```html
<h2>남은 대목</h2>
<blockquote>원문 인용</blockquote>
<p>왜 남았는가 — 내 쪽 이야기.</p>
```

- 🔴 **"왜 남았는가" 가 글이다.** 인용만 모으면 발췌집이고, 인용 없이 쓰면 감상문이다. 둘 다 필요하다
- 인용은 원문 그대로. OCR 오탈자는 문맥으로 고치되 확신 없으면 그대로 둔다
- 줄거리 칸은 **5줄을 넘기지 않는다.** 넘기면 나머지 칸이 전부 줄거리의 각주가 된다
- 1인칭을 쓴다. 평론이 아니다

**`level`** — `intro` 는 안 읽은 사람에게 (결말 없이), `working` 은 같이 읽은 사람에게,
`deep` 은 다 읽은 사람에게 (결말을 다뤄도 된다 — 글 머리에 표시).

## ③ 조립

1. 첫 문장에 **남은 한 가지**를 둔다. 줄거리로 시작하면 읽는 사람이 거기서 멈춘다
2. 남은 대목의 순서를 **감정이 쌓이는 순**으로
3. 마지막 — 질문으로 닫어도 된다. 교훈으로 닫지 않는다
4. `<section>` 이 없는지 확인

## 금지

- 줄거리가 글의 절반 이상
- 인용 없는 "남은 대목"
- 교훈으로 닫기 ("…임을 배웠다")
- 3인칭 평론체
- `<section>` 사용
