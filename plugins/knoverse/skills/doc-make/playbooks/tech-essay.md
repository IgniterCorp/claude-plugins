# tech-essay — 기술서 독후감

> **공통 규약을 먼저 읽는다** → [`_common.md`](_common.md)

기술서를 읽고 **내 판단을 담은 글**. 요약이 아니다 —
요약은 07(장별 요약)이 이미 한다. 여기서 더해지는 것은 **평가와 적용**이다.

옵션: `level` · `density`

## 요약과 무엇이 다른가

| | 장별 요약 (07) | 독후감 (여기) |
|---|---|---|
| 단위 | 장 하나 | 책 한 권 |
| 1인칭 | 없다 | **있다** — 내가 어떻게 읽었나 |
| 평가 | 없다 | **있다** — 동의·반론·한계 |
| 적용 | 없다 | **있다** — 내 일에 무엇을 바꿀까 |

🔴 **장 요약을 이어 붙인 것이 독후감이 아니다.** 그러면 "무슨 내용이었나" 만 남고
읽은 사람이 사라진다. 장별 재료는 ②에서 **근거로만** 쓴다.

## ① 아웃라인 — 주장을 먼저 세운다

**독후감은 구조가 책을 따르지 않는다.** 장 순서로 쓰면 요약이 된다.

1. 목차와 책 메타를 보고 **이 책의 중심 주장**을 한 문장으로 세운다
2. 그 주장에 대한 **내 입장**을 정한다 (동의 / 부분 동의 / 반론)
3. 그 입장을 받칠 **근거 장 3~5개**를 고른다 — 이게 본문 칸이 된다

| 칸 종류 | 수 | `chapterId` |
|---|---|---|
| 이 책의 주장과 내 입장 | 1 | null |
| **근거** — 한 칸에 한 논점 | 3~5 (`density`) | 근거 장 |
| 동의하지 않는 지점 / 한계 | 1 | 해당 장 (없으면 null) |
| 내 일에 무엇을 바꿀까 | 1 | null |
| 누가 읽어야 하나 | 1 | null |

`density`: `simple` 3칸 · `standard` 4칸 · `full` 5칸 (근거 칸 수)

**근거 장을 고르는 기준** — 책의 중요 장이 아니라 **내 입장을 가장 잘 받치는 장**이다.
반론 쪽 장도 하나 넣는다. 전부 동의하는 글은 광고처럼 읽힌다.

> 아웃라인을 사람에게 보일 때 **세운 주장과 입장을 먼저 말한다.** 그게 틀리면 글 전체가 틀리고,
> 사람이 5초 만에 고칠 수 있는 유일한 지점이다.

## ② 칸 채우기 — 근거 하나당 「사실 → 해석 → 내 판단」

```html
<h2>논점 한 문장</h2>
<p>책이 말한 것 — 사실. (3장)</p>
<blockquote>인용이 효과적이면 원문 그대로</blockquote>
<p>내가 읽은 방식 — 해석.</p>
<p>내 판단 — 그래서 맞다/아니다/조건부다.</p>
```

- 🔴 **사실과 판단을 섞지 않는다.** 섞으면 책이 그렇게 말했는지 내가 그렇게 생각하는지
  읽는 사람이 구분할 수 없다 — 독후감에서 가장 흔하게 깨지는 지점이다
- 인용은 **원문 그대로.** OCR 오탈자는 고쳐 읽되 확신 없으면 그대로 둔다
- 코드는 **거의 넣지 않는다.** 넣어야 한다면 3~5줄, 그리고 코드 자체가 논점일 때만
- "인상 깊었다" 로 끝내지 않는다. **왜** 인상 깊었는지가 글이다

**`level` 별 차이** — 독후감에서 `level` 은 **독자**를 가리킨다.

| | `intro` | `working` | `deep` |
|---|---|---|---|
| 독자 | 이 책을 안 읽은 사람 | 같은 분야 사람 | 이 책을 읽은 사람 |
| 용어 | 다 풀어 준다 | 핵심만 | 전제한다 |
| 무게 | 책이 뭘 말하는가 | 쓸 만한가 | 저자 주장에 대한 논평 |

## ③ 조립

1. **도입** — 주장과 입장을 한 단락으로. 결론을 **맨 위에** 둔다
2. 근거 칸의 순서를 **설득력 순**으로 재배치한다 (장 순서가 아니다)
3. **한계 칸이 비어 있지 않은지 확인한다.** 비면 "다 좋았다" 가 되고 글의 신뢰가 떨어진다
4. 마지막 — 누가 읽어야 하고 **누가 안 읽어도 되는지**. 후자가 더 유용하다
5. `<section>` 이 없는지 확인

## 금지

- 장 요약을 이어 붙이는 것
- 사실과 판단을 한 문장에 섞는 것
- 전부 동의 — 반론·한계가 없는 독후감
- "인상 깊었다"·"많이 배웠다" 로 끝나는 단락
- `<section>` 사용
