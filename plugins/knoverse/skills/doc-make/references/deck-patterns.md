# 슬라이드 원형과 구조 패턴

> 아웃라인을 짤 때 본다. **칸마다 어떤 원형을 쓸지** 정하는 것이 아웃라인의 절반이다.

## 🔴 16장이 전부 같은 모양이면 실패다

2026-10-05 의 deck 세 개가 그랬다 — 전부 `<h2>` + 불릿 4개. 분량 상한은 다 지켰는데
**발표자료가 아니라 요약본**이 됐다. 아웃라인에 원형을 섞어 적는다.

**20분(16장) 기준 배합** — 숫자는 하한이 아니라 **균형의 기준**이다.

| 원형 | 몇 장 | 역할 |
|---|---|---|
| 주장+근거 (불릿) | 5~7 | 기본형. 그래도 **절반을 넘기지 않는다** |
| 그림 (다이어그램·비교·타임라인) | **3~5** | 구조·흐름·대조는 글보다 그림이 빠르다 |
| 코드 | 2~4 | `examples` 옵션이 정한다 |
| 숫자 한 방 | 1~2 | 큰 글씨 하나. 기억에 박힌다 |
| 전환 | 1~2 | 다음 묶음으로 넘어가는 한 줄 |

## 원형 8가지

### 1. 주장 + 근거 (기본형)

```html
<section>
  <h2>주장 한 문장</h2>
  <ul><li>근거 2~4개</li></ul>
</section>
```

제목이 **주장**이어야 한다. "3장: 코드 악취" 는 주제고, "악취는 규칙이 아니라 길러진 코다" 가 주장이다.

### 2. 질문 열기

```html
<section>
  <p class="lead">왜 '나중에' 는 오지 않는가?</p>
  <p class="sub">답은 일정이 아니라 모자에 있다</p>
</section>
```

한 장을 **질문 하나**로만 쓴다. 듣는 사람이 답을 머릿속에 떠올릴 시간을 준다.

### 3. 숫자 한 방

```html
<section>
  <p class="lead">5.7%</p>
  <p class="sub">469,160자 원문이 요약 뒤 남은 양</p>
</section>
```

숫자 하나 + 그 숫자가 **무엇인지** 한 줄. 세 줄로 설명하면 효과가 사라진다.

### 4. 전/후 비교

좌우 2단으로 **바뀐 것만** 보인다. 같은 부분을 양쪽에 다 쓰면 차이가 안 보인다.

```html
<section>
  <h2>중첩이 사라지면 핵심이 앞으로 나온다</h2>
  <div class="two">
    <div><p class="tag">전</p><pre>...</pre></div>
    <div><p class="tag">후</p><pre>...</pre></div>
  </div>
</section>
```

### 5. 다이어그램

흐름·구조·관계는 **그림이 글보다 빠르다.** 그리는 법은 [visual-vocabulary.md](visual-vocabulary.md).

🔴 **ASCII 아트를 `<pre>` 에 넣는 것으로 때우지 않는다.** 발표 화면에서는 줄 맞춤이 깨져 보이고
크기를 못 키운다. 박스·화살표는 인라인 SVG 나 CSS 로 그린다.

### 6. 코드 + 그래서 무엇인가

코드만 띄우면 아무도 안 읽는다. **같은 슬라이드 안에** 한 줄 결론을 붙이거나 다음 장에 둔다.
코드는 **원문 그대로** — `...` 로 줄이면 안 돌아가는 코드가 된다.

### 7. 실제 사례로 다리 놓기

책 안 예시만 쓰면 **"책 얘기" 로 남는다.** 듣는 사람이 매일 쓰는 것에 붙인다 →
[tone-and-hooks.md](tone-and-hooks.md).

### 8. 전환

```html
<section>
  <p class="lead">여기까지가 '무엇'</p>
  <p class="sub">이제 '언제'</p>
</section>
```

묶음이 바뀔 때 한 장. 없으면 16장이 한 덩어리로 흘러간다.

## 전체 구조 — 서사로 간다

```
① 훅        지금 아픈 것 (질문·숫자·장면)
② 왜 이것   이 발표가 푸는 문제
③ 흐름      순서 — 장 번호가 아니라 질문 순서
④~⑬ 본문   [주장]→[그림]→[코드]→[그래서] 를 묶음으로 반복, 묶음 사이에 전환
⑭ 반전      "이럴 줄 알았는데 아니었다" — 있으면 여기가 제일 기억에 남는다
⑮ 한 장으로 핵심 3줄
⑯ 다음 행동 듣는 사람이 **내일 할 수 있는** 것 하나
```

**마지막 장은 요약이 아니라 행동이다.** "정리하면…" 으로 끝나면 아무도 안 움직인다.

## 금지

- 🔴 **메타 발언** — `"이 발표는 10장 안에서만 인용한다"` · `"이번 발표에서는 …살펴보겠습니다"` ·
  `"347~404쪽"`. 듣는 사람에게 **아무 쓸모가 없다.** 범위·출처는 발표자 노트의 일이지 화면의 일이 아니다
  (2026-10-05 에 실제로 세 덱에 다 실렸다)
- 전 슬라이드 같은 모양 (원형을 섞는다)
- 장 제목을 슬라이드 제목으로 복사 (제목은 주장이다)
- 그림 0장 (16장이면 최소 3장)
